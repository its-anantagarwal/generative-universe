# generative-universe

This is a tiny procedural universe generator made with HTML, CSS and JavaScript.

## Try it

https://generative-universe-omega.vercel.app/  
or, you can download the index.html file and run it locally.

## Features

- 300+ proceduraly generated twinkling stars
- 3 randomly generated solar systems
- A total of 8 planets
- Different planet sizes and colors. Some planets have rings.
- Procedurally generated moons.
- Asteroid belts.
- Info panels for planets.
- Generate new universes by clicking the 'Generate Universe' button.

## How it works

This project uses the canvas element of HTML and JavaScript to draw everything. The Universe is generated using Math.random(). The program stores small amounts of data such as position, size, color, orbit radius and orbit speed.  

The canvas redraws the universe every frame.
